# Settings {#guide.settings}

Settings let you change how SolvePath looks and works.

## Theme {#settings.appearance.theme}

The theme changes the app's colors.

- **Dark:** dark background, easy on the eyes. This is the starting theme.
- **Light:** light background, good in a bright room.
- **High contrast:** black and white with bright colors, for the clearest possible view.

Every theme is checked to make sure text is easy to read.
